## 🚀 Project Overview

This dashboard was created using **Microsoft Excel / Power BI** to visualize sales data interactively.  
It enables users to:
- Track **Total Sales**, **Profit**, and **Profit %** in real time  
- Compare performance by **Month**, **Product**, **Category**, and **Payment Mode**  
- Identify top‑performing items and categories  
- Understand customer behavior through **Sales Type** and **Daily Sales** insights
